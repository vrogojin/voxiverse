2026-07-25: de-orbit descent "laggy as hell" solved in 3 shipped rounds on deploy/perf-plus-sky (live-verified 56-60fps space descent, was 0.9-5fps). Non-obvious facts worth keeping:

1. **The analytic faceted query path had NO column memo**: `TerrainConfig.generated_cell` called `column_profile(x,z)` with pcache=null → `facet_profile` (f64 dir + 3D noise, ~0.1-0.25ms WASM) recomputed per CELL — a bounded floor_under scan paid ~400 recomputes of the SAME column per frame. Fixed by FP_ANALYTIC_COL_MEMO (8c90d56): route through `_acquire_facet_ctx()` exactly like `generated_cell_global` always did. The FP_FLOOR_* family had bounded scan COUNT but never per-iteration COST.
2. **Sub-ATMO_TOP(384) fall = surface `_move` regime** → per-frame floor_under while feet are 300+ blocks up; that's why the old explosion started at alt≈366, and why att=recover looked worst (2s nav dwell commits PLANETARY at y≈100-250, same band where FALL_ATT_GATE_Y=200 expires — correlation, not recover-cost).
3. **Terminal velocity trap**: braked descent settles to `ATMO_BRAKE_TERMINAL·e^(h/(2·128))`; ATMO_BRAKE_TERMINAL == ENV_FALL_HOLD_VY == 20, so FP_ENV_FALL_HOLD stays active the whole final approach and releases ~0.3s AFTER touchdown — env-resume bursts hit the landing moment (proc 391ms spikes), never mid-band. FP_ENV_RESUME_PACED (300ms) bounds it.
4. **Near-surface dip band 38-94 is geometric**: viewer r=128, terrain tops ~112 — the descending view sphere first touches ground at ~94. Streaming that disc is irreducible (#58); FP_LAND_RAMP_HOLD clamps pool grow targets to 64 during the fall (reuses the `_fall_vy_ema` signal), deferring ~75% to the post-touchdown paced ramp.
5. **Telemetry map**: `vt_total_ms` (remote_bridge) = VoxelTerrain main-thread share, comparable to worst_ms same-window; `FacetFarRing._process` (swap + the 6·K²=3456-iter visibility scans, ~5-14ms/frame each on WASM) is covered by NO instrument — `t_farring_us` only wraps main.gd's shell-driver calls. `sh_proc_us` field still a deferred follow-up, as are the floored-path re-emit growth batcher and verify_land_ramp.gd.
6. phys_ms on threaded web partly measures dlmalloc-lock WAIT (worker alloc firehose stalls main) — see [[voxiverse-walk-perf-root-cause]]; env-warm worker cycles were ~50k noise samples + whole-shell commit_to_arrays each.
