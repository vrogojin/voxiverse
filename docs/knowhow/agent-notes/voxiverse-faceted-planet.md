**THE PIVOT (2026-07-12, tasks #78/#79).** After the entire cube-sphere corner saga (#68–#77, M5c, the wedge, R2) proved the smooth cube→sphere warp fundamentally awkward — the corner-closure never worked live (wedge rendered as a 4th surface, faces not joined, terrain broke across faces, eager-flip churn = perf-degraded near corners) — the user directed: **"No more transforming cube into sphere."** Build the planet as a **FACETED piecewise-flat polyhedron**: 6·k² FLAT square-voxel facets tilted to approximate a sphere, meeting at dihedral ridges. Inside a facet: ZERO cell distortion (perfect cubes). Curvature lives ONLY at the seams. This is the opposite conclusion to the prior projection/triangular studies BECAUSE it drops lattice continuity (each facet = an independent flat world) — the escape those no-go theorems assumed away.

**Fable feasibility study: docs/COSMOS-FACETED-PLANET-STUDY.md — feasible ✓, better ✓, net-simpler ✓ (as a destination).** Gauss–Bonnet 720° is invariant; faceting spreads it over ~1,500 tiny vertices. The 8×90° cube corners DISSOLVE (measured: 2.24° @k=8, 0.60° @k=16 — validated by verify_cosmos_facet 20/0). DELETES the whole smooth-warp stack (CosmosBend, CosmosTruePlace + the C++ bake hook, M_win, fold_cell, home-face flips, the wedge, M5c) — the #68–#77 bug class dies structurally (no sliding window, no D4 flip). REUSES the flat engine wholesale (a facet == our flat world) + R2 static-node+rigid-transform + the far builder. Cost: ~5-milestone restart (planet regen) + residual seam artifacts (mild ridges, ~1.4% non-buildable seam strip, seam datum steps near old corners, 8 grid-twist singularities placeable as "navel" landmarks). Web-SAFER (stock flat meshes, no shaders, f32-safe).

**FP0 SHIPPED + user verdict "looks EXACTLY right."** cosmos_facet.gd (FacetAtlas: vertex_dir/facet_corners/facet_normal/facet_dir_at/facet_pos_at, corner_defect_deg, sample_dihedral_deg) + faceted_spike.gd (static demo planet, R=512, flat facets carrying REAL earth terrain via dir→cube cell→_curved_profile + far-palette colour, directional-lit, free-fly cam) + FACETED_SPIKE toggle (default OFF; main.gd builds the spike instead of the world). **USER'S SEAM-DESIGN DIRECTIVE (2026-07-12) — THE core requirement for the faceted engine (FP2/FP4):** "Do NOT distort the voxels themselves. On the borders, let the voxel meshes from neighbouring facets INTERSECT in real 3D space, and fill the intersecting boundary voxels with PARTIALLY-FILLING TRIANGULAR shapes that MATCH each other → smooth JUNCTION BLOCKS, each composed of the two+ matching partial blocks from the joining facet meshes. Same principle as the existing terrain smoothing." → Every voxel stays a perfect cube; the dihedral wedge at a seam is tiled by COMPLEMENTARY triangular partial-fills (one from each facet, clipped by the seam plane, no gap/overlap), ENCODED as ShapeCodec modifiers so the SAME mesher (shape_mesh) + ground_collider that draw terrain smoothing draw the junction. Render==collision, walkable (a bevel, not a wall/step). This is the user's earlier "triangular border block, 90-45-45" idea made exact and general (per-dihedral). Routed to the FP1–FP5 impl spec (Fable → docs/COSMOS-FACETED-IMPL.md).

**JUNCTION-BLOCK MODEL FORMALIZED — docs/COSMOS-FACETED-IMPL.md §3.5 (spec rev 2, commit e450973, teammate FacetImplSpec 2026-07-12).** The directive is now an exact construction for FP2/FP4: invariant I3 (voxels always perfect unit cubes; curvature absorbed ONLY at seams by geometry composition). Encoded `CellCodec.FAM_JUNCTION := 2` (the reserved FAM kind slot), 12-bit payload (slot 2 + cut offset q 5-bit 1/16-block + reserved 5); continuous α/φ/plane live EXACT in the atlas keyed by slot, only the in-cell offset quantizes, offsets round OUTWARD (overlap ∈[0,1/8], never a crack). FP4 = walkable (both sides grade to SAME integer ring datum → surfaces differ ≤0.5<STEP_MAX; no-build/no-break in-strip; wall removed).
