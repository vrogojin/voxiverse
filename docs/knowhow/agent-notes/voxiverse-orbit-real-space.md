User at live alt 8000 saw "whole planet over gray-bluish sky" instead of black space. Root cause: at orbit the camera far ramps fine (CosmosScale.camera_far → ~15458 at alt 8000, planet not clipped), sky lerps to black + fog→0 (all the on flags work) — BUT the **star dome radius `CosmosSky.d_sky_derived()` is derived from the STATIC `FacetFarRing.CAMERA_FAR=9000`** (~8143 blocks), so it does NOT track altitude. Above radial alt ≈3.5k the planet limb √(d²−R²) outgrows the dome → dome collapses into the disc → space can't composite around the limb → gray-blue wash. At alt 2507 the dome still clears the disc (why the 2507 capture showed clean black+stars); 8000 is where it fails.

**Fix = FP_SKY_DSKY_ALT** (cosmos_sky.gd): dome + sun/moon placement track `CosmosScale.camera_far(d,R)` per frame (like B5 fog-end already does). `d_sky_derived_at(d,r)=camera_far·0.95/1.05` = 1.086·limb (always clears limb), edge 1.14·limb < 1.2·limb far clip (never culled). At ground camera_far==FAR_MIN==9000 ⇒ scale==1.0 exactly ⇒ byte-identical. Applied to _stars.transform via `star_basis.scaled()` (keep star_basis PURE so shader planet_dir stays unit). Requires FP_SKY_DSKY_R (+FP_SCALED_BODY for the ramp).

**CRITICAL trap**: a blind `CAMERA_FAR` raise is WRONG — the fixed dome (derived from it) would then sit BEYOND the 9000 ground clip and cull NIGHT STARS on the surface. The dome must track altitude, not be a bigger constant.

Also shipped same commit: **FP_HUD_VACUUM_TEMP** (thermometer.gd) — clamp shown temp ≥ −273°C (orbit lapse was extrapolating to −541); air temp "--" in vacuum (radial alt > ATMO_TOP=384); ground temp "--" in space off-surface (real number again on Moon/Earth surface). Reuses `Player.radial_altitude()` + `Player.is_on_surface()` (=_space_on_ground, the telemetry alt/on_ground sources).
