Design = emit the existing tex UVs on blocky tops (node params) + walls (top-edge UVs) under `FP_BLOCKY_TEX`; zero new shader strings (reuses coverage-gated `wt·tx.a` shader), zero new memory. Bake stays analytic sample_columns (RTT rejected: unmeshed facets, readback stalls, non-determinism). **2R redesign (same day, commit 8904137)** after live user eyeball "STILL just biome COLORS, not textures": the color bake alone can never show block faces (averaged away; 1-blk faces are sub-pixel at far-ring range — 2.3px/blk at d=600). Fix = `FP_BLOCK_DETAIL` (requires FP_FACET_TEX only, T1b): ONE real block-face tile per macro texel — 16×64² Texture2DArray from the near-block PNG tiles (BlockTextures.TILES), mean-normalized (top mips → 0.5 ⇒ auto-degrades to the color map) + REPEAT + baked grid borders; separate 6×384² L8 id pages (texelFetch NEAREST, id 0=unbaked; NOT base-page alpha — protects the live-hardened premultiply/coverage law). +3 MB → 40 MB ceiling. Bake-atlas-into-pages rejected: 2.4 GB planet-wide. Block scale far = 26 blk (base texel) → 3.3 blk (closeup band) → 1 blk near.

**2U redesign (round 3, commit 02b5175)** after live eyeball of deployed FP_BLOCK_DETAIL ("repeating pattern, not real terrain" + "no grid" + "far land displaced deeper"): (1) `FP_BAND_BLOCK_MAP` — the near-far band (active+ring-1) gets a per-facet 1-byte/block id grid (9×512² L8 array, 2.4 MB) × raw shared face tiles ⇒ pixel-exact factored top-down bake (flattened bake with face detail = 44.5 MB/facet, dead); facet = residency unit (reuses fid-keyed everything), chunk-rows = bake slices. (2) grid borders removed, tiles stored RAW + tile_mean uniform keeps the mip→colormap law. (3) cull-not-sink: per-cell coverage via the skin's shipped `skin_near_meshed`/is_area_meshed probe (100 ms reap, CONFIRM=2), asymmetric hysteresis (slow cull / instant dilated un-cull); `FP_FARRING_LEVEL` collapses backstop_sink to ENV_EPS_G=1.5 + FAR_BIAS_K depth bias — closes #72 structurally; U2 strictly before U3. Ceiling 43 MB. Biggest risk = cull-seam hole race (G-CV-SAFE).
