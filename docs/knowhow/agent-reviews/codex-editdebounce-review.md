## The mechanism
Split "truth rev" (producers bump instantly, lossless) from "published rev" (what the far tier sees). An edit inside a structure bbox bumps truth rev only; the published rev/version advances only when a per-structure gate opens (idle ≥ STRUCT_EDIT_IDLE_MS=3000 AND player ≥ STRUCT_EDIT_DEPART_BLK=16.0 from the structure's world AABB). WorldManager holds a _sed_pending map (root → {last_edit_ms, world-AABB}); _sed_tick publishes gated roots atomically+coalescing. Also §3.4: the far tier's edits_rev term is rewired from raw edit_count (=_edits.size()) to a publish-bumped counter so plain-terrain digs no longer force a far rebuild.
